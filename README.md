# DIY Спектрофотометр TCD1304 (190–2050 нм)

Полноценное настольное приложение на JavaFX для работы с самодельным спектрофотометром на базе линейки ПЗС-сенсора **TCD1304DG**.

## Особенности

### ✓ Реализованные функции

- **Два способа подключения:**
  - WebSocket – беспроводное соединение с ESP32
  - Serial (COM-порт) – классическое подключение к Arduino Uno/Nano/Mega
- **Реальное время:** Живой график 3648-точечного спектра с обновлением по таймеру
- **Спектральный анализ:**
  - Захват и вычитание тёмного тока (Dark Current)
  - Захват опорного спектра (Reference)
  - Переключение в режим Absorbance (–log₁₀) с корректным вычитанием тёмного тока
- **Обработка данных:**
  - Сглаживание спектра (Moving Average фильтр)
  - Поиск локальных минимумов
  - Детекция пиков с настраиваемыми параметрами (порог, окно)
  - Подгонка базовой линии
- **Визуализация:**
  - Легенда для различных данных (Спектр, Минимумы, Пики, Базовая линия)
  - Масштаб графика (Zoom) с историей (undo/redo)
  - Тултип с координатами при наведении на график
- **Экспорт данных:**
  - Экспорт в CSV
  - Экспорт в Excel (XLSX)
  - Экспорт в PDF
- **Системные возможности:**
  - Логирование операций в реальном времени
  - Автосохранение настроек подключения
  - Настройка порога и окна для детекции пиков
  - Поддержка Arduino и шагового двигателя

### ☑️ Блоки управления

1. **Подключение:** Выбор типа подключения, адрес/COM-порт
2. **Измерения:** Кнопки для тёмного тока, опоры, захвата, сглаживания, поиска минимумов и пиков
3. **Масштаб:** Кнопки для включения зума, undo/redo масштаба
4. **Параметры пиков:** Поле ввода порога и окна детекции
5. **Логи:** Отображение истории операций с поддержкой копирования
6. **Arduino:** Управление Arduino-подключением
7. **Шаговой двигатель:** Управление шаговым двигателем

## Архитектура

### Основные компоненты

- **`SpectrometerController`** – главный контроллер приложения
- **`SpectrumChart`** – кастомный компонент для отрисовки спектра
- **`SpectrumData`** – модель данных спектра
- **`PeakDetectionService`** – сервис для детекции пиков
- **`PeakFittingService`** – сервис для подгонки пиков
- **`ExportService`** – сервис для экспорта данных
- **`LogService`** – сервис для логирования
- **`ArduinoConnectionController`** – управление Arduino
- **`StepperMotorController`** – управление шаговым двигателем

### Архитектурные принципы

- Чистая ООП-архитектура с разделением ответственности
- Использование паттерна MVC
- Сервисы для бизнес-логики
- Поддержка многопоточности через Platform.runLater()
- Легко расширяемая структура

## Требования

## Инструкции по использованию

1. Запустите приложение
2. Выберите тип подключения (WebSocket или Serial)
3. Введите адрес (для WebSocket) или выберите COM-порт (для Serial)
4. Нажмите "Подключиться"
5. Используйте кнопки управления для измерений и анализа

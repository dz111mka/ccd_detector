# DIY Спектрофотометр TCD1304 (190–2050 нм)

Полноценное настольное приложение на JavaFX для работы с самодельным спектрофотометром на базе линейки ПЗС-сенсора **TCD1304DG**.

### Особенности
- Поддержка двух способов подключения в одном окне:  
  → **WebSocket** – беспроводное соединение с ESP32  
  → **Serial (COM-порт)** – классическое подключение к Arduino Uno/Nano/Mega
- Живой график 256-точечного спектра в реальном времени
- Захват и вычитание тёмного тока (Dark)
- Захват опорного спектра (Reference)
- Переключение в режим **Absorbance** (–log₁₀) с корректным вычитанием тёмного тока
- Автосохранение последнего IP/порта и COM-настроек
- Чистая ООП-архитектура, легко расширяется

### Требования
- Java 21+
- JDK с поддержкой JavaFX (Liberica Full JDK, BellSoft, Azul Zulu и др.)
- Gradle 8.x (wrapper уже в проекте)

### Зависимости
- JavaFX 21
- Jackson (JSON)
- Java-WebSocket
- jSerialComm (для COM-портов)
